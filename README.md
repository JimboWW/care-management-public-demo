# Care Management Demo

A static, privacy-safe demonstration of a care-management workspace.

- The tracker names and tasks are fictional examples.
- Weekly tracker grids are the primary view, with today's date and column highlighted and an optional selected-day checklist.
- Demo changes are stored only in the current browser's local storage.
- Care Information supports fictional contacts, medication references, and general care references.
- Do not enter actual personal health information in this public demonstration.
- No account, backend, analytics, or external service is used.
- This demo is not a medical record or a source of medical advice.

Open `index.html` directly in a browser or serve this folder with a static HTTP server.
